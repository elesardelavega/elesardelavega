# Elesar de la Vega · Desarrollo web y soporte informático

Web profesional estática para presentar servicios de desarrollo web y asistencia informática en Zaragoza y Aragón.

## Desarrollo local

Abre `index.html` en un navegador o sirve esta carpeta con cualquier servidor estático. No necesita dependencias ni proceso de compilación.

## Publicación

GitHub Pages puede servir el contenido directamente desde la raíz de la rama `main`. Al conectar el dominio propio, actualiza los metadatos sociales y añade el dominio asignado en `CNAME`.

Los materiales de trabajo de `_work/` y el servidor local no se publican.
