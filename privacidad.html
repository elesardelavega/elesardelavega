Qué datos y para qué

El sitio es informativo y no contiene formularios propios, cuentas de usuario ni herramientas de analítica. Si escribes voluntariamente por email o WhatsApp, el titular recibirá los datos que incluyas en el mensaje para contestar a tu consulta y, cuando corresponda, preparar o gestionar una relación profesional.

Base jurídica

La respuesta a solicitudes precontractuales o la gestión de servicios se basa en las medidas solicitadas por la persona interesada y, si se inicia una relación profesional, en su ejecución. Las obligaciones legales aplicables pueden exigir conservar cierta información durante los plazos correspondientes.

Destinatarios y transferencias

El sitio se aloja en GitHub Pages. GitHub indica que, cuando se visita un sitio alojado en GitHub Pages, registra y almacena la dirección IP del visitante por motivos de seguridad. Si escribes por email o WhatsApp, esos proveedores tratarán el contenido que les envíes conforme a sus propias políticas. No se han incorporado aquí herramientas publicitarias ni analítica de terceros.

Conservación

Los mensajes se conservan durante el tiempo necesario para atender la consulta y, si se genera una relación contractual o una obligación legal, durante los plazos necesarios para gestionarla o atender responsabilidades.

Derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad cuando corresponda escribiendo a elesarvega@gmail.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

Seguridad y cambios

Se aplican medidas razonables para proteger la información recibida. Esta política puede actualizarse si cambian el sitio, sus herramientas o la normativa.
